# The Ladybug Collective Website

Static website for GitHub Pages.

## Files
- `index.html` — homepage
- `books.html` — books
- `authors.html` — authors
- `news.html` — news
- `about.html` — about
- `contact.html` — contact
- `styles.css` — site styling
- `assets/` — images

## Replace these image files
Add your real images to the `assets` folder using these exact names:
- `hero.jpg`
- `ashes-cover.jpg`
- `memoir-cover.jpg`

The website will automatically use them.

## Important
Before public launch:
1. Add real retail links on the Books page.
2. Replace the placeholder contact email if needed.
3. Add author biographies/photos if desired.
4. Connect `theladybugco.com` only after you are happy with the GitHub Pages version.
